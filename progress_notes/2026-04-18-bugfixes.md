# Bug fixes in base Optimus-1 required for memory integration

## 1. `plain_inventory` observation returns sparse slots
- File: `src/optimus1/env/plain_inventory.py`
- Bug: MCP-Reborn only reports occupied slots, so `plain_inventory` dict was missing empty slots
- Effect: crafting helper couldn't find free slots to place crafted results
- Fix: pre-initialize all 36 slots as `{"type": "none", "quantity": 0}` before merging observation

## 2. `find_in_inventory` `return result[0]` bug
- File: `src/optimus1/helper/jarvis_craft_helper.py`
- Bug: `result` from recursion was a string, `[0]` returned first character
- Fix: `return result` (fix was insufficient alone, see #3)

## 3. `find_in_inventory` bogus recursion into value dicts
- File: `src/optimus1/helper/jarvis_craft_helper.py`
- Bug: labels is flat, but the function recursed into value dicts (which only have "type"/"quantity") causing false matches like `inventory_id='type'`
- Fix: rewrote function without recursion — just iterate flat labels and match on stringified value

## Benchmark results after fixes (wooden task group)
- Craft a stick: PASS
- Craft a crafting table: PASS
- Chop a tree: PASS
- Dig dirt: PASS
- Craft a wooden pickaxe: pickaxe appears in inventory, downstream success monitor / replan logic misbehaves
